01 — Who you're hiring

I make the numbers
make sense.

I'm Adithya — a B.Tech Computer Science student at VIT-AP, Data Analytics specialisation, class of 2028, based in Hyderabad. I got here the usual way: a spreadsheet that didn't add up, and the stubborn need to know why.

Markets are where I point that stubbornness. Finance is the one field where data has real consequences — a wrong number isn't a typo, it's money. So I build the things that keep numbers honest: Python models, SQL pipelines, Excel dashboards, and risk measures like Value at Risk and Expected Shortfall that say out loud how bad a bad day can get.

Every model on this page is mine — built from scratch, backtested, and broken on purpose to find out where it fails. That's the standard client work gets too: if I hand you a number, I can show you exactly how it was made.
